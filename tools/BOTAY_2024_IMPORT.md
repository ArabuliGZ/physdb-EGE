# ЕГЭ 2024: варианты Botay

Архив `Материалы/ЕГЭ 2024 Botay/` содержит сохранённые HTML-страницы,
PDF условий, ответов и решений, все рисунки и `manifest.json` с URL, размером
и SHA-256 каждого файла. Источник — [каталог Botay за 2024 год](https://botay.pro/zadachi/varianty/ege/2024/).

| Раздел сайта | Вариант Botay | Задачи | Явные ключи | Развёрнутые решения |
| --- | --- | ---: | ---: | ---: |
| Реальный → Основной 1 | 24105 | 26 | 0 | 0 |
| Реальный → Основной 2 | 24107 | 26 | 0 | 6 |
| Реальный → Основной 3 | 24109 | 26 | 0 | 6 |
| Реальный → Открытый вариант | Открытый 1 | 26 | 6 | 6 |

PDF «с ответами» у основных вариантов не содержит ключей; PDF «с решениями»
у Основного 1 не содержит развёрнутых решений. Поэтому соответствующие поля
оставлены пустыми. Подсказки не выдаются за решения. Критериев источник не
предоставляет. Все импортированные задачи помечены `needs_review`, потому что
страница и PDF Botay являются одной публикацией, без независимой сверки с
авторским оригиналом.

Таблицы с исходными данными в Основном 1 №20, Основном 2 №20, Основном 3
№4 и №5, Открытом №20 сверены с исходными изображениями или HTML и перенесены
в `tabular`. Исходные изображения таблиц сохранены с ролью `source_page`.
Печатные таблицы для вписывания ответа у Основного 3 №10 и №17 представлены
редактируемыми полями сайта, их исходные изображения также сохранены.
Пять схем Основного 3 №20 вырезаются из одной исходной картинки по
контрольному SHA-256 и показываются по номерам. Исходник остаётся в архиве.
Рисунки в решениях Основного 2 и Открытого варианта сохранены отдельно как
`solution_figure`. Сломанные формулы PDF в решениях Открытого №25 и №26
перенабраны в TeX по отрисованным страницам 13–14.

Импорт и проверка:

```powershell
python tools/fetch_botay_2024.py
python tools/import_botay_2024.py
python tools/check_botay_2024_import.py
python tools/check_solution_formulas.py --strict
python tools/check_solution_tex.py
python tools/check_solution_tex.py --field criteria
python tools/check_text_sanity.py --strict
python tools/check_source_superscripts.py --strict
python tools/check_answer_fields.py
python tools/check_tables.py
python tools/build_automatic_variants.py
python tools/check_automatic_variants.py
```

Импортёр после повторного запуска восстанавливает все локальные правки
редактора сайта из `tools/site_edits/problem_text_edits.json`.
