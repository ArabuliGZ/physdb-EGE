# Три варианта ЕГЭ 2026 с Botay

Локальный архив находится в `Материалы/ЕГЭ 2026 Botay/`: для каждого
варианта сохранены HTML-страница с 26 задачами, PDF условий, PDF «с ответами»,
PDF «с решениями» и все рисунки. `manifest.json` содержит URL, SHA-256 и
размер каждого исходного файла. `fetch_botay_2026.py` восполняет только
отсутствующие файлы; импорт работает строго из архива и сверяет хеши.

Импорт запускается `python tools/import_botay_2026.py`, проверка —
`python tools/check_botay_2026_import.py`. Источник каждой задачи указан
как URL страницы с якорем `#zN`; PDF целого варианта используется как
дополнительный визуальный ориентир. Иллюстрации привязаны к исходным задачам
по ссылкам внутри их HTML-блоков. Таблицы, сведённые сайтом к линейному
тексту в основном варианте №4, 14 и 20, восстановлены в импортёре.

Доступность в архиве:

| Вариант | Условия | Явные ответы | Развёрнутые решения | Рисунки |
| --- | ---: | ---: | ---: | ---: |
| Основной период, Дальний Восток | 26 | 0 | 6 | 12 |
| Открытый вариант | 26 | 0 | 0 | 15 |
| Досрочный период | 26 | 26 | 6 | 15 |

У двух первых вариантов PDF, озаглавленные «с ответами», в тексте
отличаются от PDF условий только заголовком: ключей в них нет. У открытого
варианта PDF «с решениями» также не содержит решений. Отсутствующие поля
оставлены пустыми, без попыток вычислить авторский ответ. Критериев ни в
одной из сохранённых страниц нет; поле `criteria` пустое. Все записи имеют
`extraction_status=needs_review`, поскольку HTML и PDF с Botay не являются
независимыми источниками для содержательной сверки. Условия, решения и
критерии не называются авторски проверенными.

Для каталога 2027 позиции №21 (молекулярная физика вместо электродинамики)
и №23 (магнитное поле вместо молекулярной физики) помечены `no`;
остальные позиции — `yes` по теме,
формату и баллам. После каждого повторного импорта восстанавливаются
ручные правки редактора из `tools/site_edits/problem_text_edits.json`.
