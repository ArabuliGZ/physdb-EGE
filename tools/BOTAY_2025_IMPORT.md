# Варианты ЕГЭ 2025 с Botay

Архив `Материалы/ЕГЭ 2025 Botay/` содержит HTML с условиями отдельных
задач, три PDF каждого варианта и все встроенные рисунки. `manifest.json`
фиксирует URL, размер и SHA-256 каждого файла. Импорт идёт только из этого
архива командой `python tools/import_botay_2025.py`; проверка —
`python tools/check_botay_2025_import.py`.

| Вариант | Задачи | Явные ключи | Развёрнутые решения | Рисунки |
| --- | ---: | ---: | ---: | ---: |
| Центр 7 | 26 | 26 | 6 | 10 |
| Центр 6 | 26 | 0 | 0 | 10 |
| Дальний Восток 1 | 26 | 0 | 0 | 11 |
| Дальний Восток 2 | 26 | 0 | 0 | 11 |
| Сибирь 3 | 26 | 0 | 0 | 16 |

| Открытый 1 | 26 | 0 | 0 | 12 + 5 изображений таблиц |
| Досрочный 1 | 26 | 0 | 0 | 12 + 1 изображение таблицы |

У восьми вариантов PDF с пометкой «с ответами» не даёт ключей, а PDF
«с решениями» не содержит развёрнутых решений. Подсказки не перенесены
в поле решений. Критериев в архиве нет. Пустые поля остаются пустыми.

Импортёр восстанавливает 14 таблиц с данными, которые сайт представил линейным
текстом или отдельным изображением. Подписи полей ответа открытого варианта
№6, 10 и 15 сверены с изображениями исходных таблиц. Изображения таблиц
сохраняются с архивной ролью `source_page` для сверки, а на сайте показываются
набранные таблицы или поля ответа. Для уральской задачи №22 показатель степени в давлении
восстановлен по [другой публикации той же формулировки](https://onlyege.ru/wp-content/uploads/2026/06/e6-fi-var1-20.pdf);
локатор и замечание сохранены в записи. Противоречащие друг другу фразы
исходника в ДВ-2 №17 не исправлялись догадкой.

Соответствие 2027 году оценивается отдельно по каждой позиции. У задач
№21–23 встречаются разные темы в зависимости от региона; для молекулярной
задачи №22 дополнительно записано соответствие позиции №23. Все записи
пока `needs_review`: HTML и PDF Botay не являются независимыми источниками
для полной авторской сверки. После повторного импорта обязательно
восстанавливаются правки редактора сайта из
`tools/site_edits/problem_text_edits.json`.
