# Двухколоночные задания на соответствие

Для заданий, где в исходнике есть два столбца без видимых границ, сайт использует
`web/static/matching-layouts.js` и общий компонент `renderMatchingStatement` в
`web/static/app.js`. Все уже обнаруженные задания перечислены в конфигурации.

Правила для следующего импорта:

1. Сохранять в условии каждый пункт `А)`, `Б)` и `1)`–`4)` с новой строки.
   Подписи колонок («ПРОЦЕССЫ», «ФИЗИЧЕСКИЕ ВЕЛИЧИНЫ» и т. п.) оставлять
   отдельными строками. Формулы внутри пунктов записывать в TeX.
2. Рисунок общего условия прикреплять до рисунков графиков. Если графики А и Б
   являются одним изображением, ставить `graphFigures: 1`; если это два
   самостоятельных изображения, `graphFigures: 2`. Компонент помещает
   соответствующее число последних рисунков в левый столбец.
3. Задания с графиками 1–5 помечать `gallery: true`: это не пара А/Б, их
   рисунки показываются компактной пронумерованной галереей.
4. После добавления ключа `год-вариант-номер` проверять и обычную карточку,
   и предпросмотр в «Собрать вариант». Таблица ответа остаётся отдельной.

При ручном исправлении LaTeX через сайт сохранять границы пунктов: шаблон
разбирает именно строки условия. Список ключей и параметры расположения
рисунков — постоянный источник данных для этого оформления.

Рисунки, которые сами являются материалом условия (пары схем/графиков и
последовательность из трёх схем), перечислены отдельно в
`PhysEgeConditionFigureRows` того же файла. Число `2` или `3` задаёт число
равных столбцов в карточке. Рисунки, представляющие варианты ответа, в этот
перечень не входят. У каждого рисунка задачи, включая решение и предпросмотр,
есть небольшая кнопка скачивания в верхнем углу.
