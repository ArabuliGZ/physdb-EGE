# Печатный вариант PhysEGE

`variant.tex` — общий шаблон листа с условиями, `reference.tex` — общие справочные таблицы. Файл `web/variant_tex.py` подставляет в них 26 задач из базы: одну для каждой позиции. Ручная вёрстка отдельных вариантов не требуется.

Мини-шаблоны ответа в `variant.tex`: `\AnswerLine` для числа и выбора цифр, `\MatchingAnswer` для соответствия, `\PairAnswer` для результата с погрешностью и `\AnswerBoxes{2}` для задания 20. Для заданий 21–26 выводится только условие: решение пишется на бланке № 2.

Условия проходят через конвертер в `variant_tex.py`: обычный текст экранируется, математические фрагменты `\(...\)` и `\[...\]` сохраняются, таблицы переводятся в `tabularx`, рисунки условия копируются из хранилища. Ответы, решения и критерии в печатный вариант не попадают.

Ссылка «Скачать TeX» возвращает текст исходника. Для локальной компиляции варианта с рисунками нужна ссылка «Скачать TeX с рисунками (.zip)»: распакуйте архив и выполните `xelatex -interaction=nonstopmode -halt-on-error -no-shell-escape variant.tex`. Ссылка «Смотреть PDF» компилирует тот же исходник на сервере через XeLaTeX.

При изменении шаблона проверяйте компиляцию каждого варианта и страницы с рисунками, многостолбцовыми таблицами и справочными данными. В таблицах задания сохраняются исходные значения; конвертер меняет только вёрстку.
