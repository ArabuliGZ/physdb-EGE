# Печатный вариант PhysEGE

`variant.tex` — общий шаблон листа с условиями, `reference.tex` — общие справочные таблицы. `answers.tex`, `solutions.tex` и `criteria.tex` — шаблоны ответов, решений и критериев с общим стилем `materials_base.tex`. Файл `web/variant_tex.py` подставляет в них выбранные 26 задач из базы: одну для каждой позиции. Ручная вёрстка отдельных вариантов не требуется. Шаблон условий можно компилировать в редакторе без задач для просмотра его полей и справочной страницы.

Мини-шаблоны ответа в `variant.tex`: `\AnswerLineWithAffixes` для числа или последовательности цифр, `\MatchingAnswer` для соответствия и `\PairAnswerWithAffixes` для результата с погрешностью. Текст до линии и единица после неё восстанавливаются из напечатанного поля `Ответ:` исходного DOCX; если таких метаданных нет, используется явное указание единицы в условии. Для заданий с развёрнутым ответом выводится только условие: решение пишется на бланке № 2.

Условия проходят через конвертер в `variant_tex.py`: обычный текст экранируется, математические фрагменты `\(...\)` и `\[...\]` сохраняются, таблицы переводятся в `tabularx`, рисунки условия копируются из хранилища. Ответы, решения и критерии собираются в отдельные документы. Лист ответов содержит все 26 номеров и явно обозначает отсутствующие ответы. Листы решений и критериев содержат только задания с соответствующим материалом в базе. Рисунки решений входят в лист решений; баллы, заголовки критериев и пункты I)–V) печатаются отдельными блоками.

На каждой странице внизу стоит только номер: чётные страницы слева, нечётные справа. Справочные данные набраны компактнее и занимают одну страницу. Каждая задача помещается в неделимый блок `ExamTask`; если новая задача окажется выше страницы, блок пропорционально уменьшится до доступной высоты. Все текущие 19 вариантов проходят сборку без такого уменьшения.

Для каждого документа сайт предлагает TeX и PDF. Для локальной компиляции условий и решений с рисунками нужен ZIP с TeX и папкой `figures`: распакуйте архив и выполните `xelatex -interaction=nonstopmode -halt-on-error -no-shell-escape <имя файла>.tex`. PDF компилируется из того же TeX на сервере через XeLaTeX. Блоки решений и критериев не делятся между страницами; очень длинный блок пропорционально уменьшается до одной страницы.

При изменении шаблона проверяйте компиляцию каждого варианта и страницы с рисунками, многостолбцовыми таблицами и справочными данными. В таблицах задания сохраняются исходные значения; конвертер меняет только вёрстку.
